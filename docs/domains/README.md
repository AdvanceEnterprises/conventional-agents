# Domains

Domain documents (DOMAIN-XXXX) define named expertise bundles — groups of
skills plus metadata (default role, default personality, description) that
capture an area of specialization or attention focus.

Domains are orthogonal to Roles (authority boundaries), Session Modes
(operational stance), and Personalities (tone/style). They answer "what does
the agent need to know about and be good at for this kind of work?"
